# FocusFlowApp

FocusFlow is a responsive demo website for a university student time management app.

## Features

- **Academic Dashboard** with today's classes, schedule snapshot, and upcoming due items
- **Assignment Tracker** ranked by urgency/grade weight with high/medium/low visual indicators
- **Focus Mode** Pomodoro timer (default 25/5), customizable intervals, and session progress
- **Weekly Time-Blocking Calendar** with fixed lecture blocks and draggable study blocks
